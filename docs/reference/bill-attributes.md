# (이전) 법안 속성 카탈로그 — **`law-attributes` 로 대체됨**

> ## → **[[law-attributes|법령 속성 카탈로그]]** 로 이동했습니다.

이 문서는 **의안(Bill)** 의 속성을 정리한 것이었습니다. **D42**로 MVP 분석 대상이 *의안*에서 **공포 후 시행 대기 법령**으로 바뀌면서 내용 전체를 법령 기준으로 다시 쓰고 파일명을 `law-attributes.md` 로 바꿨습니다(**D44**).

**제거된 것** — 의안 고유 속성이라 MVP에 해당하지 않습니다:
의안번호 · 발의주체/발의자 · 소관위원회 · 대수·회기 · 심사단계(`stage`·`stageHistory`·`procResult`) · 신구조문대비표 · 관련 의안·비용추계서·검토보고서 · 통과 가능성 신호(공동발의자수·정당분포 등)

**바뀐 것:**
- 획득 계층이 **3개 → 2개**. `🔵B 원문 파싱`이 사라졌습니다 — 국가법령정보 API가 조문 전문·부칙·개정문을 모두 주므로 `🟢A`에 흡수됐습니다.
- 시간축이 *발의~통과 추적*에서 **확정된 시행일 기준**으로 바뀌었습니다.
- diff 원천이 *신구조문대비표*에서 **`조문변경여부` 플래그 + 개정문**으로 바뀌었습니다.

내용이 필요하면 git 이력에서 이 경로의 이전 버전을 참고하세요. 의안이 분석 대상으로 복귀하면 별도 문서로 되살립니다.

> 이 파일은 **묘비 문서**입니다 — 동결 스냅샷 [[v0.4-pipeline-refinements|v0.4]]~[[v0.7-offline-online-split|v0.7]]이 옛 경로를 링크하고 있어, 그 링크를 살리기 위해 남겨 둡니다. 새 문서에서는 참조하지 마세요.
